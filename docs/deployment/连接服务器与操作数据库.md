# 从 FinalShell 连接服务器到操作数据库的完整流程

## 一、用 FinalShell 连接云服务器

1. 打开 **FinalShell**，新建 SSH 连接（或使用已有连接）。
2. 填写：
   - **主机**：你的 ECS 公网 IP（例如 `47.110.3.177`）
   - **端口**：`22`
   - **用户名**：`root`
   - **认证**：选择「公钥」，私钥路径选本机 `C:\Users\28293\.ssh\id_ed25519`（或你实际使用的私钥）
3. 保存并连接。连接成功后终端里会看到类似 `root@iZbp1cdpxpixfu79fu8rk5Z:~#` 的提示符。

## 二、虚拟环境说明（输入指令时用哪个环境）

**当前 ECS 上未创建 Python 虚拟环境**，所有命令都是用系统自带的 `python3` 和 `pip` 执行的。

- **你现在自行连接后**：直接在项目目录下用 `python3` 即可，**不需要**先激活虚拟环境。
- 若你**之后**在项目里创建了 venv（例如 `python3 -m venv venv`），则每次要跑项目脚本前需要先激活，再输入指令：

```bash
cd /root/workspace/project/financial-news-analysis
source venv/bin/activate   # 仅当存在 venv 目录时需要
python3 news_fetcher.py --minutes 120
```

**总结**：  
- 未建 venv → 直接 `cd 项目目录` 后用 `python3`。  
- 已建 venv → 先 `source venv/bin/activate`，再在项目目录下用 `python3`。

## 三、从连接成功到可以「操作数据库」的步骤与对应代码

按顺序在 FinalShell 终端里输入即可。

### 步骤 1：进入项目目录

```bash
cd /root/workspace/project/financial-news-analysis
```

### 步骤 2：（可选）若你创建了虚拟环境，先激活

```bash
source venv/bin/activate
```

（没有 venv 就跳过。）

### 步骤 3：确认能连上云数据库（用项目配置读 .env）

```bash
python3 -c "
from config import settings
import pymysql
c = settings.db
conn = pymysql.connect(host=c.host, port=c.port, user=c.user, password=c.password, database=c.name, connect_timeout=10)
conn.ping()
print('数据库连接成功')
conn.close()
"
```

看到输出 `数据库连接成功` 即表示本机到云数据库的链路和 .env 配置都正常，可以开始「操作数据库」。

### 步骤 4：用 Python 操作数据库（查 raw_news 条数、最近几条）

```bash
python3 -c "
from models import get_db_session
from models import RawNews
from sqlalchemy import select, func
session = get_db_session()
total = session.scalar(select(func.count(RawNews.id)))
print('raw_news 总条数:', total)
rows = session.execute(select(RawNews).order_by(RawNews.news_datetime.desc()).limit(5)).scalars().all()
for r in rows:
    print(r.id, r.source, r.title[:50])
session.close()
"
```

### 步骤 5：用 MySQL 命令行客户端操作数据库（如已安装 mysql-client）

若 ECS 上安装了 `mysql` 客户端，且 RDS 允许从 ECS 内网连接，可先从 .env 拿到 `DB_HOST/DB_USER/DB_PASSWORD/DB_NAME`，再执行（把下面占位换成你 .env 里的值）：

```bash
mysql -h<DB_HOST> -u<DB_USER> -p<DB_PASSWORD> <DB_NAME> -e "SELECT COUNT(*) FROM raw_news; SELECT id, source, LEFT(title,60) FROM raw_news ORDER BY news_datetime DESC LIMIT 5;"
```

例如（仅示例，请按你 .env 修改）：

```bash
mysql -hrm-xxxxx.mysql.rds.aliyuncs.com -uuser -p你的密码 news_analysis -e "SELECT COUNT(*) AS total FROM raw_news;"
```
